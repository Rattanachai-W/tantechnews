## เกิดอะไรขึ้น

OpenAI ได้เผยแพร่ผลลัพธ์ทางคณิตศาสตร์ที่สร้างโดยโมเดล Frontier ภายในองค์กรผ่าน GitHub repository ซึ่งประกอบด้วยการพิสูจน์ในรูปแบบภาษา Lean เพื่อให้คอมพิวเตอร์ตรวจสอบได้ พร้อมเปิดเผยรายละเอียดการคำนวณที่ระบุว่าผลลัพธ์เฉลี่ยใช้ทรัพยากรเทียบเท่ากับการใช้งาน ChatGPT Pro thinking ประมาณ 3 ชั่วโมง นอกจากนี้ OpenAI ยังบริจาคเงิน 5 ล้านดอลลาร์ให้แก่โครงการใหม่ของ Simons Foundation เพื่อสนับสนุนการจัดเวิร์กชอป การประชุม และโปรแกรมพิเศษ รวมถึงให้การเข้าถึงโมเดลและทรัพยากรการคำนวณแก่ผู้วิจัยที่ได้รับการสนับสนุนจากมูลนิธิ

## ทำไมเรื่องนี้สำคัญ

การเปลี่ยนจากการประกาศผลลัพธ์เป็นการให้ Formalization ในภาษา Lean และการเปิดเผยสถิติการใช้ Compute ช่วยเพิ่มความโปร่งใสทางวิทยาศาสตร์ และเปลี่ยนบทบาทของ AI จากเครื่องมือช่วยคำนวณเป็นผู้สร้างผลลัพธ์ที่มนุษย์สามารถตรวจสอบและนำไปสร้างความเข้าใจที่ลึกซึ้งยิ่งขึ้นได้

## ผลกระทบที่น่าจับตา

- **สำหรับสังคม:** การขยายขอบเขตความรู้ทางคณิตศาสตร์: นักคณิตศาสตร์สามารถใช้ผลลัพธ์และทรัพยากรจาก OpenAI ในการตรวจสอบและต่อยอดการค้นพบใหม่ๆ เพื่อสร้างความเข้าใจในเชิงทฤษฎีที่ลึกซึ้งขึ้น

- **สำหรับนักพัฒนา:** มาตรฐานการพิสูจน์ด้วยคอมพิวเตอร์: การใช้ภาษา Lean ในการเผยแพร่ผลลัพธ์ส่งเสริมการนำเครื่องมือ Formal Verification มาใช้ในการตรวจสอบความถูกต้องของงานวิจัยทางวิทยาศาสตร์

## มุมมองของทันเทค

บทวิเคราะห์: การที่ OpenAI เลือกเผยแพร่ผลลัพธ์ผ่าน GitHub และใช้ภาษา Lean แทนการประกาศผลลัพธ์ลอยๆ แสดงให้เห็นถึงความพยายามลดช่องว่างด้านความน่าเชื่อถือ (Trust Gap) ระหว่าง AI และชุมชนวิชาการ เนื่องจากคณิตศาสตร์ต้องการความแม่นยำระดับสมบูรณ์ ผู้อ่านที่สนใจสามารถเข้าไปตรวจสอบ Proofs ใน GitHub เพื่อดูว่าโมเดลมีแนวทางการให้เหตุผลอย่างไร อย่างไรก็ตาม ข้อมูลที่ยังขาดคือรายละเอียดของตัวโมเดล Frontier ที่ใช้ ซึ่ง OpenAI ระบุว่ากำลังอยู่ในขั้นตอนการเตรียมปล่อยอย่างรับผิดชอบ ทำให้ในขณะนี้ผู้ใช้ทั่วไปยังไม่สามารถนำโมเดลตัวนี้มาทดสอบซ้ำด้วยตนเองได้
