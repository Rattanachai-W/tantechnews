## เกิดอะไรขึ้น

Mozilla เผยแพร่ข้อมูลติดตามผล 100 วันหลังรายงาน Over The Edge 2.0 โดยระบุว่า Microsoft ยังคงใช้รูปแบบการออกแบบที่ลวงผู้ใช้ (Deceptive Design) เพื่อให้ใช้ Edge เช่น การใช้ข้อความชี้นำขณะตั้งค่า PC, การเปิดลิงก์จาก Windows Search และ Widgets ใน Edge แทนเบราว์เซอร์เริ่มต้น, การคงค่า Edge เป็นตัวเปิดไฟล์ PDF/SVG และการที่ Copilot เปิดลิงก์ใน side-panel ของตัวเองในทุกภูมิภาค รวมถึงการที่ Windows Backup พยายามตั้งค่า Edge เป็นค่าเริ่มต้นขณะย้ายข้อมูลไป Windows 11

## ทำไมเรื่องนี้สำคัญ

เบราว์เซอร์เป็นเลเยอร์สำคัญในการเข้าถึงเครื่องมือ AI และกำหนดมาตรฐานความเป็นส่วนตัวและความปลอดภัย การที่ผู้ผลิต OS พยายามจำกัดทางเลือกของผู้ใช้จะส่งผลต่อการเข้าถึงบริการ AI และระดับการคุ้มครองข้อมูลที่ผู้ใช้จะได้รับ

## ผลกระทบที่น่าจับตา

- **สำหรับผู้ใช้งาน:** ถูกจำกัดอิสระในการเลือกซอฟต์แวร์: ผู้ใช้นอกเขตเศรษฐกิจยุโรป (EEA) ต้องเผชิญกับประสบการณ์การใช้งานที่ด้อยกว่าและถูกบีบให้ใช้ Edge ผ่านกลไกของระบบปฏิบัติการ

- **สำหรับสังคม:** มาตรฐานการคุ้มครองสิทธิผู้บริโภคที่ไม่เท่าเทียม: การที่ Microsoft ยอมปรับปรุงการออกแบบเฉพาะในพื้นที่ที่มีกฎหมาย DMA บังคับ สะท้อนว่าบริษัทให้ความสำคัญกับการปฏิบัติตามกฎหมายมากกว่าหลักการด้านผู้ใช้

## มุมมองของทันเทค

บทวิเคราะห์: กรณีนี้ชี้ให้เห็นว่าการแข่งขันในตลาดเบราว์เซอร์ยุค AI กำลังเข้มข้นจนนำไปสู่การใช้ Deceptive Design เพื่อรักษาฐานผู้ใช้ ซึ่ง Microsoft ใช้ความได้เปรียบจากการเป็นเจ้าของ OS ในการสร้างกำแพงล้อมรอบระบบนิเวศของตน ผู้อ่านสามารถตรวจสอบการตั้งค่า Default Apps ใน Windows ของตนเองเพื่อดูว่ามีการเปลี่ยนแปลงโดยไม่ตั้งใจหรือไม่ และข้อมูลที่ยังขาดคือการตอบสนองอย่างเป็นทางการจาก Microsoft ต่อข้อค้นพบชุดล่าสุดนี้

## สรุปในประโยคเดียว

> Mozilla รายงานว่า Microsoft ยังคงใช้ดีไซน์ลวงใน Windows และ Copilot เพื่อบีบผู้ใช้ให้ใช้ Edge โดยยอมปรับปรุงเฉพาะในยุโรปตามกฎหมาย DMA
