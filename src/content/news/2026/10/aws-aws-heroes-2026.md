## เกิดอะไรขึ้น

AWS ได้ประกาศแต่งตั้งสมาชิกใหม่ 3 รายเข้าสู่โปรแกรม AWS Heroes ซึ่งเป็นกลุ่มผู้เชี่ยวชาญระดับโลกที่ช่วยแบ่งปันความรู้และให้คำปรึกษาแก่ชุมชน ได้แก่ Avinash Shashikant Dalvi จากอินเดีย (Serverless Hero), Joanne Skiles จากสหรัฐอเมริกา (Serverless Hero) และ Xiaofei Li จากจีน (Community Hero)

## ทำไมเรื่องนี้สำคัญ

โปรแกรม AWS Heroes เป็นการรับรองผู้เชี่ยวชาญที่มีบทบาทสำคัญในการสร้าง Community และถ่ายทอดความรู้ทางเทคนิค ซึ่งสมาชิกใหม่ทั้ง 3 รายมีความเชี่ยวชาญเฉพาะด้านที่หลากหลาย เช่น Serverless, Containers, AI และการสร้างเครือข่ายผู้ใช้งานในระดับภูมิภาค ซึ่งช่วยให้องค์กรและนักพัฒนาเข้าถึงแนวทางปฏิบัติที่ดีที่สุด (Best Practices) ในการใช้งาน AWS ได้ง่ายขึ้น

## ผลกระทบที่น่าจับตา

- **สำหรับนักพัฒนา:** การเข้าถึงแหล่งความรู้และ Mentor: นักพัฒนาสามารถเรียนรู้เทคนิคการสร้างแอปพลิเคชันระดับ Production ผ่านเนื้อหาและกิจกรรมที่เหล่า AWS Heroes จัดทำ เช่น จดหมายข่าว, YouTube และการบรรยายในงานคอนเฟอเรนซ์

- **สำหรับสังคม:** การส่งเสริมความหลากหลายในสายงานเทคโนโลยี: มีการสนับสนุนกลุ่มนักศึกษาที่ขาดโอกาสและโครงการ Women in Tech ผ่านการดำเนินงานของสมาชิก AWS Heroes

## มุมมองของทันเทค

บทวิเคราะห์: การคัดเลือก AWS Heroes ในรอบนี้สะท้อนให้เห็นว่า AWS ให้ความสำคัญกับ 'Serverless' และ 'Community Localization' อย่างมาก โดยเฉพาะการขยายฐานผู้ใช้ในจีนผ่านการแปล AWS Builder Cards และการสร้างกลุ่มผู้ใช้ขนาดใหญ่ ซึ่งชี้ให้เห็นว่ากลยุทธ์ของ AWS คือการใช้ผู้เชี่ยวชาญในท้องถิ่นเป็นตัวขับเคลื่อนการยอมรับเทคโนโลยี ผู้อ่านที่ต้องการพัฒนาทักษะด้าน Serverless หรือ AI สามารถติดตามผลงานของ Joanne Skiles หรือ Avinash Shashikant Dalvi เพื่อดูตัวอย่างการนำไปใช้จริง อย่างไรก็ตาม ข้อมูลในประกาศนี้ไม่ได้ระบุเกณฑ์การคัดเลือกที่ชัดเจนสำหรับผู้ที่ต้องการสมัครเข้าโปรแกรมในอนาคต

## สรุปในประโยคเดียว

> AWS แต่งตั้งผู้เชี่ยวชาญ 3 รายจากอินเดีย สหรัฐฯ และจีน เข้าสู่โปรแกรม AWS Heroes เพื่อสนับสนุนชุมชนนักพัฒนาด้าน Serverless และ Cloud ทั่วโลก
