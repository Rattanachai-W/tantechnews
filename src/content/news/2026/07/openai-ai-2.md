## เกิดอะไรขึ้น

OpenAI ระบุว่าผู้ใช้หลายล้านคนทั่วยุโรปใช้เครื่องมือของ OpenAI เพื่อเรียนรู้ สร้างผลงาน ทำงาน และจัดการงานประจำวัน และเครื่องมือยังสนับสนุนธุรกิจทุกขนาดรวมถึงรัฐบาล OpenAI ประกาศว่าเมื่อ EU AI Act เข้าสู่ช่วงถัดไป บริษัทได้เสริมแนวทางด้านความปลอดภัย ความมั่นคง โปร่งใส และการพิสูจน์แหล่งที่มาให้สอดคล้องกับกรอบ EU โดยมีส่วนร่วมและรับรอง Code of Practice สองฉบับ ได้แก่ EU GPAI Code of Practice และ Code of Practice on Transparency of AI-Generated Content OpenAI ยังทดสอบโมเดลก่อนเปิดตัว เผยแพร่ System Cards ใช้ Red Teaming Network และรักษา Model Spec สาธารณะ รวมถึงใช้ Preparedness Framework ที่เริ่มตั้งแต่ปี 2023 และปรับปรุงในปี 2025 กับ Frontier Governance Framework เพื่อประเมินและจัดการความเสี่ยงจาก AI ขั้นสูง

## ทำไมเรื่องนี้สำคัญ

สำคัญเพราะ EU AI Act กำลังเข้าสู่ช่วงถัดไป และ OpenAI เป็นหนึ่งในผู้ให้บริการ AI ที่ถูกใช้โดยผู้ใช้ ธุรกิจ และรัฐบาลในยุโรป การปรับแนวทางให้สอดคล้องกับ GPAI Code และแนวปฏิบัติด้านความโปร่งใสของเนื้อหา AI ช่วยกำหนดมาตรฐานความปลอดภัย การประเมินความเสี่ยง การรายงานโมเดล การตอบสนองต่อเหตุการณ์ และการพิสูจน์แหล่งที่มา ซึ่งส่งผลต่อความเชื่อมั่นและการแข่งขันของยุโรป

### สำหรับสังคม

สังคมยุโรป: การมีส่วนร่วมใน Code of Practice สองฉบับและการร่วมมือผ่าน Frontier Model Forum, US CAISI และ UK AISI ช่วยส่งเสริมความปลอดภัยร่วม การทดสอบภายนอก และมาตรฐานการประเมินที่ชัดเจนในนิเวศ AI

### สำหรับผู้อ่าน
