## เกิดอะไรขึ้น

OpenAI ประกาศลดราคา GPT-5.6 Luna 80% และ GPT-5.6 Terra 20% ใน API โดยราคาใหม่ยังสะท้อนในวิธีนับการใช้งานกับแผนชำระเงินของ Codex และ ChatGPT Work นอกจากนี้ OpenAI เปิดตัว Fast mode ใน API แทนที่ Priority Processing โดย GPT-5.6 Sol ใน Fast mode เร็วขึ้นสูงสุด 2.5 เท่าเมื่อเทียบกับการประมวลผลมาตรฐาน ในราคา 2 เท่า โดยไม่เปลี่ยนระดับความฉลาด และคำขอที่ติดป้าย priority จะใช้ Fast mode อัตโนมัติ

## ทำไมเรื่องนี้สำคัญ

การลดราคาและเพิ่มความเร็วทำให้ทีมพัฒนาและธุรกิจสามารถเลือกโมเดลตามผลลัพธ์ที่ต้องการได้ เช่น ใช้ GPT-5.6 Sol สำหรับขั้นตอนที่ต้องใช้ความฉลาดสูง และใช้ GPT-5.6 Luna สำหรับงานปริมาณมากที่เร็วและต้นทุนต่ำ โดยบทความระบุว่า Luna ให้ประสิทธิภาพใกล้เคียงโมเดลระดับ frontier เมื่อหนึ่งปีก่อนในต้นทุนประมาณ 6 เซนต์ต่อ 1 ดอลลาร์ต่องาน และเร็วกว่าเกือบ 9 เท่า
