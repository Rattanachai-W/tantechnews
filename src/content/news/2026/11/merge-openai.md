## เกิดอะไรขึ้น

Merge พัฒนาชุดผลิตภัณฑ์เพื่อช่วยบริษัทสร้างซอฟต์แวร์และ AI products ประกอบด้วย Merge Unified สำหรับรวมข้อมูลลูกค้า, Merge Agent Handler สำหรับให้ AI agents เข้าถึงเครื่องมืออย่างปลอดภัย, Merge Gateway สำหรับจัดการ Model routing และควบคุมค่าใช้จ่าย รวมถึง Merge for Workforce สำหรับบริหารจัดการการเข้าถึงโมเดลและระบบภายในองค์กร โดยภายในบริษัท Merge เองมีการใช้ Codex ในการรีวิวโค้ด และใช้ GPT-6 Astra ในการทดสอบผลิตภัณฑ์ การตลาด และการบริหารจัดการงานภายใน เช่น การใช้บอทช่วยเตรียมงานเลี้ยงอาหารค่ำสำหรับลูกค้า

## ทำไมเรื่องนี้สำคัญ

การนำ AI มาใช้ในระดับโครงสร้างพื้นฐานช่วยเพิ่มประสิทธิภาพการทำงานอย่างมีนัยสำคัญ โดย Shensi Ding CEO ของ Merge ระบุว่า Tool calls ผ่าน Merge มีอัตราความสำเร็จ 99.9% ซึ่งสูงกว่า public MCP servers ที่อยู่ที่ประมาณ 60% นอกจากนี้การใช้ GPT-6 Astra ยังช่วยให้การรีวิวโค้ดรวดเร็วขึ้นและมีความสามารถในการจดจำคำสั่งที่ซับซ้อนได้ดีกว่าระบบ AI อื่นๆ

## ผลกระทบที่น่าจับตา

- **สำหรับนักพัฒนา:** เพิ่มประสิทธิภาพการพัฒนาและรีวิวโค้ด: สามารถใช้ AI เช่น Codex และ GPT-6 Astra ในการรีวิวโค้ดและตรวจสอบการนำไปใช้งาน (Implementation) เพื่อลดข้อผิดพลาดและปรับปรุง UX ของผลิตภัณฑ์

- **สำหรับธุรกิจ:** ลดความซับซ้อนในการเชื่อมต่อระบบธุรกิจ: สามารถใช้ AI Agents ทำงานข้ามระบบธุรกิจได้ผ่านตัวเชื่อมต่อที่เสถียร และบริหารจัดการการเข้าถึงเครื่องมือของพนักงานได้อย่างเป็นระบบ

## มุมมองของทันเทค

บทวิเคราะห์: ความแตกต่างของอัตราความสำเร็จในการเรียกใช้เครื่องมือ (Tool calls) ระหว่าง 99.9% ของ Merge และ 60% ของ MCP servers ชี้ให้เห็นว่าเลเยอร์การจัดการ (Orchestration layer) ที่ดีมีความสำคัญพอๆ กับตัวโมเดล AI เอง ผู้อ่านที่กำลังพัฒนา AI Agent ควรตรวจสอบว่าโครงสร้างการเชื่อมต่อข้อมูล (Connectors) ของตนมีความเสถียรเพียงใดก่อนนำไปใช้ในระดับ Production เนื่องจากความผิดพลาดเพียงเล็กน้อยในขั้นตอน Tool calling อาจทำให้ Workflow ทั้งหมดล้มเหลว โดยข้อมูลที่ยังขาดคือรายละเอียดทางเทคนิคว่า Merge ใช้วิธีการใดในการเพิ่มความแม่นยำให้สูงกว่ามาตรฐานทั่วไป

## สรุปในประโยคเดียว

> Merge ใช้เทคโนโลยี OpenAI พัฒนาเครื่องมือเชื่อมต่อข้อมูลและ AI Agents โดยชูจุดเด่นด้านความเสถียรของ Tool calls ที่สูงถึง 99.9%
