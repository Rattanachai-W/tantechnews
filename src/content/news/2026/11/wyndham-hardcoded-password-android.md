## เกิดอะไรขึ้น

Robert Wiggins นักวิจัยด้านความปลอดภัยจาก What Security พบรหัสผ่านที่ถูกฝังไว้ในซอร์สโค้ด (Hardcoded) ของแอปพลิเคชัน Wyndham บน Android ซึ่งรหัสนี้สามารถใช้เข้าถึงฐานข้อมูลภายในของบริษัทที่โฮสต์บน Salesforce ได้ โดยข้อมูลที่ถูกเปิดเผยประกอบด้วย ชื่อ, อีเมล, หมายเลขสมาชิก และ Login Tokens (JWTs) รวมถึงไฟล์เอกสารต่างๆ ของบริษัท ซึ่งฐานข้อมูลดังกล่าวมีข้อมูลหลายล้านรายการ โดยทาง Wyndham ได้ทำการยกเลิกรหัสผ่านดังกล่าวทันทีหลังจาก TechCrunch ประสานงานให้

## ทำไมเรื่องนี้สำคัญ

เหตุการณ์นี้แสดงให้เห็นถึงความเสี่ยงขั้นรุนแรงจากการ Hardcoding หรือการใส่รหัสผ่านลงในซอฟต์แวร์โดยตรง ซึ่งเป็นข้อผิดพลาดพื้นฐานที่ทำให้ผู้ไม่หวังดีสามารถดึงรหัสผ่านออกมาจากแอปที่เผยแพร่สู่สาธารณะและเข้าถึงฐานข้อมูลหลังบ้านได้โดยง่าย นอกจากนี้ยังสะท้อนถึงการขาดช่องทางรายงานช่องโหว่ (Vulnerability Disclosure Program) ของบริษัท

## ผลกระทบที่น่าจับตา

- **สำหรับผู้ใช้งาน:** ความเสี่ยงด้านข้อมูลส่วนบุคคล: ข้อมูลชื่อ อีเมล และ Token สำหรับล็อกอินถูกเปิดเผย ซึ่งอาจนำไปสู่การสวมรอยเข้าใช้งานบัญชีหรือการโจมตีแบบ Phishing

- **สำหรับธุรกิจ:** ความเชื่อมั่นและข้อกำหนดทางกฎหมาย: บริษัทเผชิญคำถามเรื่องการแจ้งเตือนลูกค้าและการรายงานเหตุการณ์ต่อหน่วยงานกำกับดูแล เช่น SEC ตามข้อกำหนดของบริษัทมหาชน

- **สำหรับนักพัฒนา:** มาตรฐานการเขียนโค้ดและความปลอดภัย: เป็นบทเรียนสำคัญในการห้ามฝัง Credentials ลงในซอร์สโค้ด และชี้ให้เห็นว่าเครื่องมือ AI สามารถช่วยตรวจหาช่องโหว่ประเภทนี้ได้อย่างรวดเร็ว

## มุมมองของทันเทค

บทวิเคราะห์: สาเหตุหลักของเหตุการณ์นี้เกิดจากความประมาทในการจัดการ Secret Management โดยการใช้ Hardcoded Password ซึ่งเป็นช่องโหว่ระดับวิกฤตที่ตรวจพบได้ง่ายแม้ใช้เครื่องมือ AI พื้นฐาน สิ่งที่น่ากังวลคือ Wyndham ไม่สามารถยืนยันได้ว่ามี Log ที่ตรวจสอบย้อนหลังได้หรือไม่ว่ามีผู้ไม่หวังดีรายอื่นเข้าถึงข้อมูลก่อนหน้านี้หรือไม่ ผู้อ่านที่เป็นนักพัฒนาควรตรวจสอบการเก็บรักษา API Keys และ Passwords โดยใช้ Environment Variables หรือ Secret Management Tools แทนการเขียนลงในโค้ด และองค์กรควรจัดทำ Vulnerability Disclosure Program เพื่อให้ผู้เชี่ยวชาญแจ้งเตือนช่องโหว่ได้อย่างปลอดภัยก่อนจะกลายเป็นข่าวสาธารณะ

## สรุปในประโยคเดียว
