## เกิดอะไรขึ้น

GitHub รายงานว่าในหนึ่งสัปดาห์ของเดือนตุลาคมมีการ Commit โค้ดมากกว่า 1.2 พันล้านครั้ง ซึ่งเพิ่มขึ้นกว่า 400% เมื่อเทียบกับปีก่อน และมากกว่าจำนวน Commit ทั้งปี 2025 อย่างไรก็ตาม ผลการศึกษาจาก Faros AI พบว่าเมื่อทีมมีการนำ AI มาใช้ในระดับสูง ระยะเวลาในการรีวิว Pull Request กลับเพิ่มขึ้นถึง 441% GitHub จึงนำเสนอเวิร์กโฟลว์ Agentic Engineering ที่แบ่งเป็น 4 ระยะคือ Plan, Build, Verify และ Observe โดยในระยะ Plan จะใช้ Copilot รวบรวมบริบทจากเครื่องมือต่างๆ เช่น Slack หรือ Teams เพื่อสร้างแผนการดำเนินงานและ GitHub Issues พร้อมระบบคัดกรองงาน (Triage) เพื่อมอบหมายงานที่ซับซ้อนน้อยให้ AI จัดการโดยอัตโนมัติ

## ทำไมเรื่องนี้สำคัญ

การเพิ่มขึ้นของปริมาณโค้ดที่สร้างโดย AI ไม่ได้ส่งผลให้ผลิตภาพ (Productivity) เพิ่มขึ้นในสัดส่วนเดียวกัน เนื่องจากเกิดคอขวดในขั้นตอนการตรวจสอบและรีวิว การเปลี่ยนผ่านสู่ Agentic Engineering จึงสำคัญเพราะเป็นการเปลี่ยนบทบาท AI จากเพียงผู้ช่วยเขียนโค้ด (Code Generation) ไปเป็นผู้ช่วยบริหารจัดการกระบวนการพัฒนาทั้งระบบ เพื่อลดภาระด้านการรวบรวมข้อมูลและการจัดการงานรูทีนของนักพัฒนา

## ผลกระทบที่น่าจับตา

- **สำหรับนักพัฒนา:** ลดภาระงานธุรการและการรวบรวมบริบท: นักพัฒนาสามารถใช้ AI Agent ช่วยรวบรวมความต้องการที่กระจัดกระจายจากหลายเครื่องมือมาสร้างเป็นแผนงานและ Issue ที่ชัดเจน ทำให้มีเวลาโฟกัสกับการตัดสินใจในเชิงเทคนิคที่ซับซ้อนมากขึ้น

- **สำหรับธุรกิจ:** แก้ปัญหาคอขวดในกระบวนการ Review: องค์กรที่นำ AI มาใช้สร้างโค้ดจำนวนมากต้องเผชิญกับระยะเวลาการรีวิวที่นานขึ้น การใช้ Agentic Workflow จะช่วยให้การส่งต่องานมีเกณฑ์การยอมรับ (Acceptance Criteria) ที่ชัดเจนขึ้น ซึ่งช่วยลดเวลาในขั้นตอนการตรวจสอบ

## มุมมองของทันเทค

บทวิเคราะห์: ปรากฏการณ์ที่จำนวน Commit เพิ่มขึ้น 400% แต่ระยะเวลาการรีวิวเพิ่มขึ้น 441% สะท้อนว่า AI กำลังสร้าง 'หนี้ทางเทคนิค' หรือภาระในการตรวจสอบที่สูงขึ้นหากใช้เพียงเพื่อการ Generate โค้ด การนำ Agentic Engineering มาใช้เพื่อจัดการบริบท (Context) ในขั้นตอน Plan จึงเป็นทางออกที่สมเหตุสมผล เพราะปัญหาหลักไม่ได้อยู่ที่การเขียนโค้ด แต่อยู่ที่การสื่อสารและความเข้าใจที่ตรงกัน ผู้อ่านควรตรวจสอบว่าในทีมมีการกำหนด Acceptance Criteria ที่ชัดเจนก่อนให้ AI เขียนโค้ดหรือไม่ เพื่อลดเวลาในการรีวิว และควรทดลองใช้ AI ในการทำ Triage งานเบื้องต้นเพื่อลดภาระการจัดการ Issue

## สรุปในประโยคเดียว

> GitHub นำเสนอ Agentic Engineering เพื่อใช้ AI Agent ช่วยบริหารจัดการวงจรการพัฒนาซอฟต์แวร์แบบครบวงจร แก้ปัญหาคอขวดในการรีวิวโค้ดที่เพิ่มสูงขึ้นจากการใช้ AI เขียนโค้ดเพียงอย่างเดียว
