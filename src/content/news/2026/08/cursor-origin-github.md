## เกิดอะไรขึ้น

Cursor เปิดตัว Origin แพลตฟอร์มโฮสต์โค้ดที่รองรับการทำงานร่วมกัน การเรียกดูและแก้ไขโค้ด การจัดการ pull request และการเก็บ repository โดยออกแบบให้ซิงก์กับ GitHub ได้โดยไม่ต้องเลิกใช้ GitHub Cursor ระบุว่าฟีเจอร์ agent native และระบบ app ecosystem จะพร้อมใช้งานใน Origin การเปิดตัวตรงกับช่วงที่ GitHub มี outage ทั่วโลกนานกว่า 6 ชั่วโมงและมี error rate ราว 20%

## ทำไมเรื่องนี้สำคัญ

Origin เป็นทางเลือกใหม่สำหรับนักพัฒนาที่ต้องการโฮสต์โค้ดและจัดการ pull request ในระบบที่เชื่อมกับ GitHub ได้ โดยเฉพาะในช่วงที่ GitHub มีปัญหา outage บ่อยครั้ง โดย LeadDev รายงานว่า GitHub มี outage 257 ครั้งในรอบปี และผู้ใช้ระดับสูงบางส่วนย้ายออก

### สำหรับธุรกิจ

### สำหรับสตาร์ทอัพ
