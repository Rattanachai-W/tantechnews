## เกิดอะไรขึ้น

OpenAI ให้บริการ Zero Data Retention สำหรับลูกค้า API ที่เข้าเงื่อนไข โดยไม่เก็บ prompts หรือคำตอบของโมเดลหลังประมวลผล และเปิดให้ทดลอง Private Safety Processing เพื่อตรวจจับรูปแบบความเสี่ยงข้ามหลายการโต้ตอบ โดยพนักงาน OpenAI ไม่เข้าถึงเนื้อหา

## ทำไมเรื่องนี้สำคัญ

สำคัญเพราะโมเดล frontier ทำงานยาวและซับซ้อนขึ้น ความเสี่ยงเห็นชัดเมื่อมองหลายการโต้ตอบร่วมกัน ZDR ช่วยองค์กรไม่ต้องยอมให้ผู้ให้บริการเก็บเนื้อหาอ่อนไหวเพื่อความปลอดภัย และลูกค้ายังควบคุมข้อมูลได้

## ผลกระทบที่น่าจับตา

### สำหรับนักพัฒนา

ทางเลือก ZDR สำหรับ API: ลูกค้า API ที่เข้าเงื่อนไขสามารถใช้งาน Zero Data Retention โดย OpenAI ไม่เก็บ prompts หรือคำตอบของโมเดลหลังประมวลผล และข้อมูลองค์กรไม่ใช้ฝึกโมเดลเว้นแต่เลือก opt-in

### สำหรับธุรกิจ

ควบคุมข้อมูลและรักษาความปลอดภัย: องค์กรสามารถเก็บเนื้อหาบนโครงสร้างพื้นฐานที่ลูกค้าควบคุม และ OpenAI กำลังพัฒนาตัวเลือกเก็บบน OpenAI infrastructure ที่เข้ารหัสด้วยคีย์ที่ลูกค้าควบคุม โดยพนักงาน OpenAI ไม่มีคีย์และเข้าถึงเนื้อหาไม่ได้

### สำหรับผู้อ่าน

ระบบความปลอดภัยข้ามหลายการโต้ตอบ: Private Safety Processing ตรวจจับรูปแบบความเสี่ยงข้ามหลายการโต้ตอบและส่งสัญญาณความปลอดภัยจำกัดให้ OpenAI โดยไม่เปิดเนื้อหาให้พนักงานเข้าถึง
