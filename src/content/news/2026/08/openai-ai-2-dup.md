## เกิดอะไรขึ้น

OpenAI เผยแพร่รายงาน Enterprise Signals และงานวิจัย How Organizations Use AI: Evidence from ChatGPT พบว่าองค์กรธุรกิจกำลังขยายการใช้ AI จากคำถามสู่การดำเนินงานจริง โดยจนถึงเดือนมิถุนายน Codex สร้าง output tokens 64% ของผลรวม Codex และ ChatGPT ในกลุ่มลูกค้าองค์กร องค์กรแนวหน้าซึ่งอยู่ใน 10% แรกของการใช้ AI รายเดือนสร้าง output tokens ต่อผู้ใช้ที่ใช้งานจริง 8.3 เท่าขององค์กรทั่วไป เพิ่มขึ้นจาก 2.6 เท่าในเดือนมกราคม และผู้ใช้รายสัปดาห์ในองค์กรแนวหน้าใช้ Plugins 21% เทียบกับ 9% ในองค์กรทั่วไป

## ทำไมเรื่องนี้สำคัญ

ข้อมูลนี้สำคัญเพราะชี้ว่า AI ในองค์กรไม่ได้ถูกใช้เพียงตอบคำถามอีกต่อไป แต่เริ่มเชื่อมต่อเครื่องมือ บริบท และงานซ้ำ ๆ เพื่อสร้างผลลัพธ์ที่ตรวจสอบได้ การที่ Codex สร้าง output tokens 64% และพนักงานระดับเริ่มต้นใช้ AI มากกว่าพนักงานอาวุโส บ่งบอกว่าการออกแบบสิทธิ์ การกำกับดูแล และการแปลงงานส่วนบุคคลเป็นกระบวนการร่วมจะกลายเป็นประเด็นหลักขององค์กร

## ผลกระทบที่น่าจับตา

### สำหรับธุรกิจ

### สำหรับนักพัฒนา

นักพัฒนาต้องออกแบบ agent ให้ทำงานหลายขั้นตอน: Codex สร้าง output tokens 64% ของผลรวม Codex และ ChatGPT ในลูกค้าองค์กร และ workflow แบบ agent สร้าง output มากกว่าเพราะทำงานหลายขั้นตอน ทำให้การออกแบบเครื่องมือ สิทธิ์ และการตรวจสอบผลลัพธ์มีความสำคัญ

### สำหรับผู้อ่าน
