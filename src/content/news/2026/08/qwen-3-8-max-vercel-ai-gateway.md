## เกิดอะไรขึ้น

Vercel ประกาศว่า Qwen 3.8 Max ใช้งานได้แล้วบน AI Gateway โดยโมเดลรองรับงานข้อความและงานภาพ-ภาษาในโมเดลเดียว มีพารามิเตอร์ 2.4 ล้านล้าน และหน้าต่างบริบทสูงสุด 1 ล้านโทเคน ผู้ใช้ตั้งค่า model เป็น alibaba/qwen3.8-max ได้ และเชื่อมต่อ coding agent เช่น Claude Code, Codex, OpenCode หรือ Pi ผ่านคำสั่ง vercel ai-gateway coding-agents setup

## ทำไมเรื่องนี้สำคัญ

สำคัญเพราะรวมความสามารถด้านข้อความและภาพในโมเดลเดียว พร้อมบริบท 1 ล้านโทเคน และพารามิเตอร์ 2.4 ล้านล้าน ทำให้พัฒนาซอฟต์แวร์ งานสำนักงาน และงานภาพ เช่น แปลงหน้าจอหรือไฟล์ดีไซน์เป็นหน้าเว็บได้ ขณะที่ AI Gateway ให้ API รวม ติดตามการใช้งานและต้นทุน ตั้งค่า retry, failover และสะท้อนราคาผู้ให้บริการโดยไม่มีค่าเพิ่ม
