## เกิดอะไรขึ้น

Microsoft ประกาศเปิดตัว Fabric IQ ซึ่งเป็นฟีเจอร์ที่นำบริบททางธุรกิจที่ผ่านการกำกับดูแล (Governed business context) เช่น semantic models, ตัวชี้วัด (metrics) และคำนิยามทางธุรกิจจาก Power BI เข้ามาใช้ใน Microsoft Copilot Chat และ Cowork โดยปัจจุบันเปิดให้ใช้งานทั่วไป (GA) แล้ว และกำลังเตรียมรวมเข้ากับประสบการณ์ด้าน Code ผ่านโปรแกรม Frontier

## ทำไมเรื่องนี้สำคัญ

การใช้ AI ในองค์กรมักประสบปัญหาเรื่องความถูกต้องของข้อมูล (Grounding) ซึ่ง Fabric IQ แก้ปัญหานี้โดยให้ Copilot ดึงข้อมูลจากแหล่งเดียวกับที่ใช้ในรายงานขององค์กร ทำให้ลดการโต้เถียงเรื่องความถูกต้องของตัวเลข และรักษามาตรฐานการควบคุมการเข้าถึงข้อมูล (Access controls) และการกำกับดูแล (Governance) เดิมที่มีอยู่

## ผลกระทบที่น่าจับตา

- **สำหรับธุรกิจ:** เพิ่มความแม่นยำในการตัดสินใจด้วย AI: องค์กรสามารถใช้ Copilot สอบถามข้อมูลทางธุรกิจ เช่น การพยากรณ์ยอดขาย โดยได้รับคำตอบที่อ้างอิงจากโมเดลข้อมูลที่เชื่อถือได้ของบริษัทโดยตรง

- **สำหรับนักพัฒนา:** การขยายขีดความสามารถของ AI ผ่าน Semantic Model: นักพัฒนาและผู้ดูแลข้อมูลสามารถนำโครงสร้างข้อมูลที่มีอยู่เดิมใน Power BI มาใช้เป็นฐานความรู้ให้ AI โดยไม่ต้องสร้างระบบ Grounding ใหม่ทั้งหมด

## มุมมองของทันเทค

บทวิเคราะห์: การเปิดตัว Fabric IQ แสดงให้เห็นว่า Microsoft กำลังเปลี่ยนจุดเน้นจากความสามารถของ LLM ทั่วไป ไปสู่การสร้าง 'Enterprise Context' โดยใช้ Power BI เป็นตัวกลาง ซึ่งเป็นกลยุทธ์ที่ชาญฉลาดเพราะเป็นการดึงฐานผู้ใช้เดิมให้ผูกติดกับ Ecosystem ของ Fabric มากขึ้น ผู้ใช้งานควรตรวจสอบว่า Semantic Model ใน Power BI ของตนเองมีการจัดระเบียบและนิยามข้อมูลที่ชัดเจนเพียงใด เพราะคุณภาพของคำตอบจาก Copilot จะขึ้นอยู่กับความถูกต้องของโมเดลข้อมูลเหล่านี้โดยตรง สิ่งที่ยังขาดคือรายละเอียดเกี่ยวกับประสิทธิภาพในการประมวลผลข้อมูลขนาดใหญ่ (Latency) เมื่อต้องดึงข้อมูลผ่าน Fabric IQ ในสถานการณ์จริง

## สรุปในประโยคเดียว

> Microsoft เปิดตัว Fabric IQ เชื่อมต่อข้อมูลจาก Power BI เข้ากับ Copilot เพื่อให้ AI ตอบคำถามธุรกิจได้อย่างแม่นยำตามบริบทจริงขององค์กร
