## เกิดอะไรขึ้น

Microsoft ประกาศอัปเดต Copilot โดยเพิ่ม 3 ความสามารถหลัก ได้แก่ 'Home' ซึ่งรวม Chat และ Cowork เข้าด้วยกัน พร้อมผสาน Word, Excel และ PowerPoint ให้ทำงานได้โดยตรงในแอป, 'Code' ที่ใช้เทคโนโลยีเดียวกับ GitHub Copilot เพื่อให้ผู้ใช้สร้างและรันโซลูชันของตนเองได้อย่างปลอดภัย และ 'Autopilot' ซึ่งเป็น AI Agent ส่วนตัวที่ทำงานเชิงรุกได้แม้ผู้ใช้ไม่ได้สั่งการ นอกจากนี้ยังเพิ่มฟีเจอร์ FinOps for AI เพื่อช่วยบริหารจัดการค่าใช้จ่ายในการใช้งาน AI

## ทำไมเรื่องนี้สำคัญ

การเปลี่ยนแปลงนี้เปลี่ยน Copilot จากเครื่องมือแชทโต้ตอบ ให้กลายเป็นระบบปฏิบัติการ AI ที่รองรับการทำงานแบบ End-to-End โดยเฉพาะฟีเจอร์ Cowork ที่สามารถรับมอบหมายงานซับซ้อนให้ทำจนเสร็จ และการเชื่อมต่อกับ Office แบบ Real-time ที่ลดปัญหาเรื่องการจัดฟอร์แมตหรือการสลับแอปไปมา

## ผลกระทบที่น่าจับตา

- **สำหรับผู้ใช้งาน:** ประสบการณ์การทำงานที่ไร้รอยต่อ: ผู้ใช้สามารถสร้างและแก้ไขเอกสาร Office ได้โดยตรงผ่าน Copilot โดยไม่ต้องสลับแอป และมี Autopilot ช่วยจัดการงานเชิงรุก

- **สำหรับนักพัฒนา:** การสร้างโซลูชัน AI ที่เข้าถึงง่ายขึ้น: สามารถใช้ฟีเจอร์ Code เพื่อสร้างและรันโซลูชันของตนเองผ่านเทคโนโลยีระดับเดียวกับ GitHub Copilot

- **สำหรับธุรกิจ:** การควบคุมต้นทุนและเพิ่มประสิทธิภาพองค์กร: ใช้ FinOps for AI ในการจัดการงบประมาณ และใช้ Skills เพื่อนำความเชี่ยวชาญเฉพาะทาง เช่น ด้านกฎหมายหรือการเงิน มาสร้าง Workflow ที่ใช้ซ้ำได้ในองค์กร

## มุมมองของทันเทค

บทวิเคราะห์: การนำ Office เข้ามาอยู่ใน Copilot โดยตรงและเพิ่มระบบ Cowork แสดงให้เห็นว่า Microsoft กำลังเปลี่ยนผ่านจาก AI Assistant ไปสู่ AI Agent ที่เน้นผลลัพธ์ (Outcome-based) มากกว่าแค่การตอบคำถาม อย่างไรก็ตาม ผู้ใช้ควรตรวจสอบเงื่อนไขการเข้าถึง เนื่องจาก Home และ Code จะเริ่มปล่อยในโปรแกรม Frontier และ Autopilot จะอยู่ในช่วง Private Preview ซึ่งยังไม่ใช่การเปิดใช้งานทั่วไปทันที ข้อมูลที่ยังขาดคือรายละเอียดราคาของฟีเจอร์ใหม่เหล่านี้ และเกณฑ์การคัดเลือกผู้เข้าร่วมโปรแกรมทดสอบ

## สรุปในประโยคเดียว

> Microsoft อัปเกรด Copilot เพิ่ม Home, Code และ Autopilot เพื่อเปลี่ยน AI จากผู้ช่วยแชทให้เป็น Agent ที่ทำงานซับซ้อนและสร้างโซลูชันได้ในตัว
